Project ModernizeOps Notes:

Set Email:
git config --global user.email "mirrellk@verizon.net"
git config --global user.email

Remote URL:
git remote add origin https://github.com/mirrellk/modernizeops.git

To Stop Ollama:
Get-Process ollama* | Stop-Process

To Start Ollama:
Start-Process ollama -ArgumentList serve -WindowStyle Hidden
Invoke-RestMethod http://localhost:11434

To Start MCP Inspector:
npx @modelcontextprotocol/inspector uv run python -m mcp_servers.kb_server.server

Example, a Git Commit of Phase 4:
git add -A; git commit -m "feat(mcp): phase 4 keystone-kb MCP server"; git push

MCP Servers in .mcp.json:

{
  "mcpServers": {
    "kb": {
      "command": "uv",
      "args": ["run", "python", "-m", "mcp_servers.kb_server.server"],
      "env": { "OLLAMA_HOST": "${OLLAMA_HOST:-http://localhost:11434}" }
    },
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": {
        "Authorization": "Bearer ${GITHUB_PAT}",
        "X-MCP-Toolsets": "repos,pull_requests"
      }
    },
    "jira": {
      "command": "uvx",
      "args": ["mcp-atlassian"],
      "env": {
        "JIRA_URL": "${JIRA_URL}",
        "JIRA_USERNAME": "${JIRA_USERNAME}",
        "JIRA_API_TOKEN": "${JIRA_API_TOKEN}",
        "JIRA_PROJECTS_FILTER": "MOD",
        "ENABLED_TOOLS": "jira_get_issue,jira_search,jira_add_comment,jira_transition_issue,jira_get_transitions"
      }
    },
    "context7": {
      "type": "http",
      "url": "https://mcp.context7.com/mcp",
      "headers": { "CONTEXT7_API_KEY": "${CONTEXT7_API_KEY:-}" }
    }
  }
}

Validate JSON:
Get-Content .mcp.json -Raw | ConvertFrom-Json | Out-Null; if ($?) { "JSON OK" }1
